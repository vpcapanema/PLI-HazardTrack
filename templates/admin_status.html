Visão geral

Cada bolinha resume um pedaço do sistema. Verde é tudo nos conformes, amarelo é "está rolando mas merece atenção", vermelho pede ação.

Fontes externas

Serviços de terceiros dos quais o sistema depende. Se um deles cair, a aplicação degrada de forma controlada e mostra "sem dado".

Plataforma e runtime

Onde o servidor está rodando, qual a versão do Python, dependências instaladas e variáveis de ambiente que controlam o comportamento.

Pipeline de dados

Cada 10 minutos o sistema roda um ciclo: busca os GRIBs do INPE, amostra os pontos, calcula RD e publica. Aqui você vê se o último ciclo deu certo, quanto demorou e o histórico recente.

Modelo e metodologia

Parâmetros do modelo DER-SP / REGEA-NIPPON 2021. As regiões e o Risco Analisado (RA) são a parte "estática" — só mudam quando há novo levantamento de campo.

Aplicação web

Rotas registradas no Flask, assets estáticos e identificação da sessão atual.

Autenticação

O login do /admin valida gestores no SIGMA-PLI (API HTTP preferida ou PostgreSQL read-only). Apenas usuários com perfil GESTOR conseguem entrar.
